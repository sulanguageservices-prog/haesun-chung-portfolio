# Haesun Chung — Bilingual Portfolio

Korean/English portfolio website for business coach Haesun Chung, built with Next.js (App Router) and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # production
npm run lint
```

## Customize

- Copy (EN/KO): `lib/content.ts`
- Colors/fonts: `tailwind.config.ts`, `app/layout.tsx`
- SEO metadata: `app/layout.tsx` (set `NEXT_PUBLIC_SITE_URL` to your domain)
- Contact email and the sample result figures/testimonials are placeholders — replace with real details.
